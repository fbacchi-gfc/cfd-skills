El script ahora genera 3 documentos (en lugar de 2):

1. {prefix}.json
   → Config estructurada (Gmsh, Salome, ICEM)

2. {prefix}_icem_notes.txt  ← NUEVO
   → Parámetros dimensionado ICEM CFD
   → Tamaños: Global, Superficies, Curvas, Inflación
   → Workflow paso-a-paso
   → Parámetros copiar-pegar al final

3. {prefix}_fluent_notes.txt
   → Setup Fluent (como antes)

4. {prefix}_debug.txt
   → Valores internos (como antes)

================================================================================
PARÁMETROS ICEM GENERADOS
================================================================================

El archivo {prefix}_icem_notes.txt contiene:

1. BASE SIZE (Global)
   Tamaño para todo el dominio far-field
   Ejemplo: 2.0e-02 m

2. LOCAL SIZES - SURFACES
   Superficies del airfoil/cilindro (upper, lower)
   Ejemplo surface size: 1.78e-03 m
   Ejemplo LE (leading edge): 1.11e-03 m

3. LOCAL SIZES - CURVES
   Contornos y bordes
   Ejemplo airfoil: 2.22e-03 m
   Ejemplo far-field: 4.0e-02 m

4. INFLATION LAYERS
   Boundary layer resolution
   First height (Δy): 2.22e-05 m
   # Layers: 749
   Growth ratio: 1.2

5. REFINEMENT ZONES
   LSB region, wake refinement
   Tamaños y ubicaciones específicas

6. PARÁMETROS COPIAR-PEGAR
   Todos los valores listados para fácil ingreso en ICEM UI

================================================================================
WORKFLOW ICEM RÁPIDO
================================================================================

1. python scripts/mesh_calculator.py \
     --re 61400 --fluid water --char-length 0.1 \
     --model rans-sst --y-plus 0.5 --deltax-plus 50 \
     --output sd8020_icem

   → Genera sd8020_icem_icem_notes.txt

2. Abrir ICEM CFD
   
3. File > Open > airfoil.iges
   
4. Geometry > Primitive > Box (crear dominio)
   Dimensiones: {upstream + downstream} × {height}
   
5. Geometry > Boolean > Subtract (airfoil del dominio)

6. Mesh > Global Size > 2.0e-02 (o valor del archivo)

7. Surfaces > Select airfoil > Properties > Mesh Size > 1.78e-03

8. Curves > Leading edge > Properties > Mesh Size > 1.11e-03

9. Inflation > New Inflation
   ├─ First height: 2.22e-05
   ├─ Layers: 749
   └─ Growth ratio: 1.2

10. Mesh > Compute
    → Genera malla unstructured

11. File > Export > Fluent Case (.cas)
    → Importar a Fluent y ejecutar
